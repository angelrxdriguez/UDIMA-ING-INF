Simulacro

Simulacro de examen: unidades 1 a 4

Cómo hacerlo. De una sentada, sin apuntes ni esta guía, con papel en blanco. Apunta cuánto tardas. Escribe como en el examen: matrices intermedias, operaciones encima de cada flecha, conclusión con una frase y sin decimales. Después corrígete con las soluciones siendo estricto: un problema solo cuenta si está entero y bien. Con 8 o 9 bien, este bloque está listo; con 6 o 7, repasa las lecciones de los que fallaste y repite el simulacro una semana después; con menos, vuelve a las listas de control.
  1. (UD1) Calcula la distancia desde el punto $Q=(4,2,1)$ a la recta intersección de los planos $\ x+y-z=1\ $ y $\ x-y+z=3$. Expresa el resultado sin decimales.
  2. (UD2) Resuelve por Gauss y sustitución hacia atrás: $\ \ y+2z=1,\quad x+y+z=2,\quad 2x-y+3z=8$.
  3. (UD2) Resuelve por Gauss-Jordan obteniendo la forma escalonada reducida por filas de la matriz ampliada. Di si es compatible y si es determinado o indeterminado; en ese caso, expresa la solución con parámetros $s$, $t$: $$2x+4y+z+4w=8,\qquad x+2y+w=3,\qquad -x-2y+z+w=-1$$
  4. (UD2) Discute, usando eliminación gaussiana (no por determinantes), según los valores de $a$: $\ \ x+y+z=1,\quad x+2y+az=2,\quad 2x+ay+4z=3$.
  5. (UD3) Calcula por Gauss-Jordan la inversa de $A=\M{rrr}{1&1&0\\2&3&1\\1&1&1}$ y úsala para resolver $A\mathbf x=\mathbf b$ con $\mathbf b=(2,7,4)$.
  6. (UD4) Calcula el determinante $\left|\begin{matrix}1&-1&2&1\\1&-1&0&0\\-1&3&2&2\\2&2&0&-1\end{matrix}\right|$.
  7. (UD4) Discute según $a$ el sistema $\ \ x-y+az=0,\quad 2x+ay+z=2,\quad -x+y+z=0\ $ usando el determinante. Para $a=0$, resuélvelo por Cramer.
  8. (UD4) Realiza la factorización LU de $A=\M{rrr}{1&-1&2\\2&1&1\\-1&4&-1}$, comprueba el resultado y úsala para resolver $A\mathbf x=\mathbf b$ con $\mathbf b=(1,5,6)$.
  9. (UD4) Calcula $\det(A-\lambda I)$ para $A=\M{rrr}{1&2&0\\2&1&0\\0&0&3}$, iguala el resultado a 0 y obtén las raíces del polinomio.
Soluciones del simulacro

Soluciones del simulacro

1. Distancia punto-recta ($\sqrt6$)

{{chain rrr|r : 1 1 -1 1 ; 1 -1 1 3 :: F2-F1 :: -1/2F2 :: F1-F2 ! piv}}

$x=2$, $y-z=-1$. Con $z=t$: $\ x=2,\ y=-1+t,\ z=t$. Punto $P=(2,-1,0)$, director $\mathbf d=[0,1,1]$. $\mathbf v=Q-P=[2,3,1]$; $\ \mathbf d\cdot\mathbf v=4$, $\mathbf d\cdot\mathbf d=2$; $\ \operatorname{proy}_{\mathbf d}\mathbf v=2[0,1,1]=[0,2,2]$; $\ \mathbf w=\mathbf v-\operatorname{proy}=[2,1,-1]$ (compr.: $\mathbf w\cdot\mathbf d=0+1-1=0$ \ok). Distancia $=\sqrt{4+1+1}=\boxed{\sqrt6}$.

2. Gauss y sustitución hacia atrás ($x=2,\ y=-1,\ z=1$)

{{chain rrr|r : 0 1 2 1 ; 1 1 1 2 ; 2 -1 3 8 :: F1<->F2 :: F3-2F1 :: F3+3F2 ! piv}}

$7z=7\Rightarrow z=1$; $\ y+2=1\Rightarrow y=-1$; $\ x-1+1=2\Rightarrow x=2$. Compr. en la 3.ª: $4+1+3=8$ \ok

3. Gauss-Jordan con dos parámetros

{{chain rrrr|r : 2 4 1 4 8 ; 1 2 0 1 3 ; -1 -2 1 1 -1 :: F1<->F2 :: F2-2F1, F3+F1 :: F3-F2 ! piv}}

Ya es la FERF (pivotes 1 en las columnas de $x$ y $z$, con ceros encima y debajo). $r=r'=2<4$: compatible indeterminado con dos parámetros. Variables libres $y=s$, $w=t$: $\ x+2s+t=3$, $\ z+2t=2$: $$x=3-2s-t,\qquad y=s,\qquad z=2-2t,\qquad w=t$$

Compr. con $s=t=1$: $(0,1,0,1)$ en la 1.ª: $0+4+0+4=8$ \ok

4. Discusión por Gauss

$$\M{rrr|r}{1&1&1&1\\1&2&a&2\\2&a&4&3}\xrightarrow{\substack{F_2-F_1\\F_3-2F_1}}\M{ccc|c}{1&1&1&1\\0&1&a-1&1\\0&a-2&2&1} \xrightarrow{F_3-(a-2)F_2}\M{ccc|c}{1&1&1&1\\0&1&a-1&1\\0&0&a(3-a)&3-a}$$

Fila 3: $2-(a-2)(a-1)=-a^2+3a=a(3-a)$ y $1-(a-2)=3-a$. (Sumar a una fila un múltiplo de otra vale aunque el multiplicador tenga $a$; lo que no se puede es dividir entre algo que puede ser 0.)

  • $a=0$: fila 3 $[0\ 0\ 0\,|\,3]$, $r=2<r'=3$: incompatible.
  • $a=3$: fila 3 de ceros, $r=r'=2<3$: compatible indeterminado.
  • $a\neq0$ y $a\neq3$: $r=r'=3$: compatible determinado (con $z=\tfrac1a$).

5. Inversa por Gauss-Jordan y sistema

{{chain rrr|rrr : 1 1 0 1 0 0 ; 2 3 1 0 1 0 ; 1 1 1 0 0 1 :: F2-2F1, F3-F1 :: F2-F3 :: F1-F2 ! piv}}

$A^{-1}=\M{rrr}{2&-1&1\\-1&1&-1\\-1&0&1}$. Compr. fila 1 de $A$: $(2-1,\ -1+1,\ 1-1)=(1,0,0)$ \ok $\ \mathbf x=A^{-1}\mathbf b=(4-7+4,\ -2+7-4,\ -2+0+4)=\boxed{(1,1,2)}$. Compr.: $1+1=2$ \ok $\ 2+3+2=7$ \ok $\ 1+1+2=4$ \ok

6. Determinante 4 × 4 ($-12$)

{{chain rrrr : 1 -1 2 1 ; 1 -1 0 0 ; -1 3 2 2 ; 2 2 0 -1 :: F2-F1, F3+F1, F4-2F1 :: F2<->F3 :: F4-2F2 :: F4-6F3 ! piv}}

Diagonal $1\cdot2\cdot(-2)\cdot(-3)=12$. Un intercambio cambia el signo: $\ \det=\boxed{-12}$. (Las demás operaciones no lo cambian.)

7. Discusión con el determinante y Cramer

$\det A=\left|\begin{matrix}1&-1&a\\2&a&1\\-1&1&1\end{matrix}\right|=a+1+2a-(-a^2+1-2)=a^2+3a+2=(a+1)(a+2)$.

  • $a\neq-1,-2$: $\det A\neq0$, compatible determinado.
  • $a=-1$: la fila 3 $[-1,1,1\,|\,0]$ es la 1.ª $[1,-1,-1\,|\,0]$ cambiada de signo; $F_3+F_1$ = ceros y $F_2-2F_1=[0,1,3\,|\,2]$: $r=r'=2$, indeterminado.
  • $a=-2$: $F_2-2F_1=[0,0,5\,|\,2]$, $F_3+F_1=[0,0,-1\,|\,0]$; $F_2\leftrightarrow F_3$ y $F_3+5F_2=[0,0,0\,|\,2]$: incompatible.

$a=0$: $|A|=2$; $\ x=\tfrac12\left|\begin{smallmatrix}0&-1&0\\2&0&1\\0&1&1\end{smallmatrix}\right|=\tfrac22=1$, $\ y=\tfrac12\left|\begin{smallmatrix}1&0&0\\2&2&1\\-1&0&1\end{smallmatrix}\right|=\tfrac22=1$, $\ z=\tfrac12\left|\begin{smallmatrix}1&-1&0\\2&0&2\\-1&1&0\end{smallmatrix}\right|=\tfrac02=0$. Solución $(1,1,0)$. Compr.: $1-1=0$ \ok $2+0=2$ \ok $-1+1=0$ \ok

8. Factorización LU y sistema

{{chain rrr : 1 -1 2 ; 2 1 1 ; -1 4 -1 :: F2-2F1, F3+F1 :: F3-F2 ! piv}}

Multiplicadores $-2$, $+1$, $-1$ → en $L$: $2$, $-1$, $1$. $\ L=\M{rrr}{1&0&0\\2&1&0\\-1&1&1}$, $\ U=\M{rrr}{1&-1&2\\0&3&-3\\0&0&4}$. Comprobación $LU$: fila 2: $2(1,-1,2)+(0,3,-3)=(2,1,1)$ \ok; fila 3: $-1(1,-1,2)+(0,3,-3)+(0,0,4)=(-1,4,-1)$ \ok ① $y_1=1$; $\ 2+y_2=5\Rightarrow y_2=3$; $\ -1+3+y_3=6\Rightarrow y_3=4$. ② $4z=4\Rightarrow z=1$; $\ 3y-3=3\Rightarrow y=2$; $\ x-2+2=1\Rightarrow x=1$. Solución $\boxed{(1,2,1)}$.

9. Raíces de $\det(A-\lambda I)$

$\left|\begin{matrix}1-\lambda&2&0\\2&1-\lambda&0\\0&0&3-\lambda\end{matrix}\right|=(3-\lambda)\big[(1-\lambda)^2-4\big]=(3-\lambda)(\lambda^2-2\lambda-3) =-\lambda^3+5\lambda^2-3\lambda-9$ (desarrollando por la fila 3). Por Ruffini (o factorizando: $\lambda^2-2\lambda-3=(\lambda-3)(\lambda+1)$): raíces $\lambda=3$ (doble) y $\lambda=-1$.
